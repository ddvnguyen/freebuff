# DM Mono

Google Fonts' DM Mono, bundled locally for Desktop code blocks, diffs, file editors,
and terminals. Regular (400) and Medium (500) are the same font files already
shipped by the iOS and Android clients in this repository.

Source: https://github.com/google/fonts/tree/main/ofl/dmmono
