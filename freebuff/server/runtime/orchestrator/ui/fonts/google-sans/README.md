# Google Sans

Unmodified Google Fonts WOFF2 subsets used by `freebuff/web/src/lib/fonts.ts`.
Normal and italic variable faces support weights 400–700. The unicode ranges
and subset binaries are copied from the existing local web build so Desktop
uses the same font without downloading fonts at runtime.

Vite copies this public directory into the packaged renderer, including OFL.txt.

Upstream: https://github.com/googlefonts/googlesans
License: https://github.com/google/fonts/blob/main/ofl/googlesans/OFL.txt
