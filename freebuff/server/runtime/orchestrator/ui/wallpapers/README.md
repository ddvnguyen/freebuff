# Bundled wallpaper sources

These files ship locally with the app; selecting a preset never loads a third-party URL.
Each image is cropped to 16:10 and resized to exactly 2560 × 1600, then encoded as WebP
(quality 74–84; finely detailed water and paper grain use the lower end). `thumbs/` holds
640 × 400 copies that the preset gallery loads instead of the full images. No external
metadata or executable content is retained.

No built-in preset uses `courtyard.webp` any more (it is 1280 × 720). It stays bundled
because saved custom presets may still name it, and the browser workspace drops a saved
preset whose bundled image is missing. The illustration is disclosed by its creator as
generated with Grok Imagine and contains no licensed anime characters.
